# Contributing to Draft

> **Vibecoders welcome.** `AGENTS.md` gets your agent running in minutes. The scaffold test is fully offline — start there.

## Quickstart

```powershell
php tests/scaffold_test.php   # must print OK
php -l scaffold.php
```

## Rules

Short version: see `AGENTS.md`. Long version: original work only, drop-lists over fences, golden tests for every template change, leanness as a feature.

## Pull request workflow

1. Fork and branch from `main`.
2. `php tests/scaffold_test.php` green, `php -l` clean on touched files.
3. Describe what changes for scaffolded projects (module, theme, or both).
